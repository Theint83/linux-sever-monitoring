# linux-sever-monitoring
Linux Server Performance and Web Monitoring System
##Project Objective
To analyze Linux web server logs and
monitor web traffic, errors, server logs and
suspicious sctivities.

## Technologies
-Ubantu Linux
-Apache Web Server
-Python
-Flask
-Html/CSS/JavaScript
-SQLite

## Main Features
-Web Server Log Collection
-log Analysis
-Traffic Monitoring
-Error Monitoring
-Suspicious Activity Detection
-Web Dashboard
-Alert System
